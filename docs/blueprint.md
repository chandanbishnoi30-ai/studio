# **App Name**: StudyFlow

## Core Features:

- Course Organization: Allow users to create courses, add assignments, and set due dates.
- AI Study Plan Generator: AI-powered tool that generates a personalized study plan based on the courses selected, deadlines, and user-specified available study hours.
- Progress Tracking: Visualize study progress with charts and graphs.
- AI Summarizer: Summarize learning materials from links, texts, or PDFs to identify key concepts, leveraging AI summarization techniques.
- Notifications: Send reminders for upcoming deadlines and study sessions.
- Cloud Storage: Use Cloud SQL to persist user data, course materials and study plans.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5), promoting focus and intellectualism.
- Background color: Very light indigo (#E8EAF6), soft and unobtrusive.
- Accent color: Purple (#7E57C2), offering a stimulating contrast.
- Body and headline font: 'Inter', a sans-serif typeface known for clarity.
- Use clear, geometric icons for course categories and actions.
- Employ a clean, card-based layout to organize courses and assignments.
- Subtle animations for task completion and deadline reminders.
